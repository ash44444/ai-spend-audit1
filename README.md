# AI Spend Audit

AI Spend Audit is a SaaS-style web application that helps startups and engineering teams identify overspending across AI tooling such as Cursor, Claude, ChatGPT, GitHub Copilot, Gemini, and others.

Users input their current AI stack, plans, and spend, and receive actionable optimization recommendations with estimated monthly and annual savings.

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL
- React Hook Form
- Zod
